# EduBuds

EduBuds is a structured Islamic Studies curriculum for Grades 1–9, with four modules per grade and carefully balanced learning across belief, action, du‘as, etiquettes, history and biographies, and tafseer.

This folder is a complete Hatchable project. Everything the app needs is in these files: pages, API routes, database migrations, seed data, and the hatchable.toml manifest that declares the services and keys it uses.

To run your own copy, bring this folder to https://hatchable.com/deploy as a .zip or as a Git repository.
